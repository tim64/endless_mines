# 💣 Mine Bombers Retro

Ретро-игра с видом сверху на чистом Canvas 2D и TypeScript, вдохновленная классической игрой **Mine Bombers** (1995).

## 🎮 Особенности игры

- ⛏️ **Псевдобесконечный мир на чанках:** процедурная генерация тайлов и естественных подземных пещер с помощью **Simplex Noise**.
- 🔥 **Лава и гидродинамика (Cellular Spread):**
  - Очаги раскаленной лавы замурованы глубоко в толще гранита и камня.
  - Стоит прокопать стенку к карману лавы — и раскаленная магма с шипением и искрами устремляется в тоннель игрока!
  - Лава освещает тьму теплым пульсирующим светом и наносит урон от огня при контакте.
  - Взрывы бомб охлаждают лаву, кристаллизуя её обратно в твердый гранит (базальт)!
- 💎 **Градация сложности и ресурсов:**
  - *Земля* — мягкая порода для легкого старта.
  - *Камень и Гранит* — требуют улучшенных кирок или динамита.
  - *Уголь и Сера* — ингредиенты для крафта пороха и бомб.
  - *Железо и Самоцветы* — редкие ресурсы в глубине для продвинутых улучшений.
- 💣 **Взрывчатка и разрушаемость:**
  - Установка бомб на таймер (2.5 сек).
  - Разрушение породы ударной волной с разлетом осколков.
  - Опасность для самого шахтера (ударная волна наносит урон игроку, если не успеть отбежать!).
- 🔨 **Верстак и крафт прямо в шахте:**
  - Создание бомб из угля и серы.
  - Улучшение кирки (Деревянная -> Каменная -> Железная -> Алмазная).
  - Создание полевых аптечек (+50 HP).
  - Улучшение дальности фонаря.
- 💡 **Атмосферный туман войны и динамический свет:**
  - Подземная тьма рассеивается лучом налобного фонаря.
  - Вспышки и искры от зажженного фитиля и взрывов.
- 🔊 **Процедурный ретро-звук:**
  - Генерация звуков копания, хруста породы, шипения фитиля и грохота взрывов на лету через **Web Audio API** (без внешних mp3-файлов!).

## 🕹️ Управление

| Клавиша | Действие |
| :--- | :--- |
| **W, A, S, D** / **Стрелки** | Перемещение шахтера |
| **ЛКМ** (по блоку рядом) | Копать выбранную породу |
| **Пробел** | Копать в сторону взгляда |
| **E** или **ПКМ** | Установить бомбу с таймером |
| **Колесо мыши** | Зум камеры |

## 🚀 Быстрый запуск

```bash
# Установка зависимостей (один раз)
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка готового бандла (всего ~24 КБ!)
npm run build
```
